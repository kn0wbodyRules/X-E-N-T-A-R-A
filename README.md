# X E N T A R A

Websites for local businesses in Trichy: gyms, stores and bakeries.

## Sites

| Client | Folder | Status |
|---|---|---|
| Xtreeme Fitness Studio, Thiruverumbur | [`site/xtreeme`](site/xtreeme) | Demo for the pitch |

To view a site, open its `index.html` in a browser. There is no build step.

## Claude Code setup

`.claude/settings.json` turns on Anthropic's official **frontend-design** plugin for anyone who opens this repo in Claude Code. You'll be asked to trust the repo once, and after that the plugin loads by itself whenever you ask for UI work. To install it by hand instead:

```
/plugin marketplace add anthropics/claude-code
/plugin install frontend-design@claude-code-plugins
```

Each site has a `DESIGN.md` with its colour, type and layout plan, written before the code.
